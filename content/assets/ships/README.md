# 舰船运行模型

yamato、bismarck、california、yorktown 各目录保存对应 GLB、LICENSE.txt、source.json 与 conversion.json。

大和衍生模型遵守 CC BY-SA 4.0，其余三舰页面标注 CC BY 4.0；具体作者、上游来源和修改说明以各模型记录为准。复制来源记录不意味着分发其中列出的原始下载。

使用根目录的 `npm run convert:yamato` / `npm run convert:ships` 从本地研究原件重建。转换报告描述当前运行导出；研究区旧报告只作历史记录。约克镇仅外形接入，不代表已经实现舰载机战斗。
