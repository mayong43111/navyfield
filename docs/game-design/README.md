# 游戏设计

存放核心循环、战斗、任务、舰船装备、成长与数值原则的 Markdown 文档；每条规则注明目标、单位、适用范围和版本。

当前启用12舰目标规则，使用压缩游戏单位；已接主炮、鱼雷、航空、自动副炮/小AA与手动两用主炮。仍是单机1对1；全舰队、占点、修理、存档和联机尚未实现。模块/数据/操作与验证边界见[运行接入说明](runtime-target.md)。

独立的[目标数值方案](balance-target.md)已完成CSV编辑源、离线试算与生成报告，覆盖舰型规模、装甲/弹药/火力公式、地图/准备/接敌和其他机制；现由CSV导出为当前运行规则，旧内核保留兼容。

v1.2补充[自动副炮/防空设计](automatic-weapons.md)及[12艘真实舰名与模型核实](ship-models.md)，只保留AP/HE炮弹和独立鱼雷；自动炮玩法已接入，但不是12种真实运行模型：4个现有参考模型上游待核，8个缺失明确显示定位框。

v1.3.0新增[炮位、攻击能力与控制方式](weapon-controls.md)：全12舰分类检查，弗莱彻原4管主炮新增手动两用防空及18条误差/组合试算，BB保留现控制策略；大口径重防空缺口未擅自补装。副炮不是自动炮，防空也不全自动。最终操作修订1在同一文档补齐选炮位/炮座、用途/弹种、齐射/渐次、逐管装填与自动组启停，并提供[独立状态回放](../../design-data/reports/weapon-controls.json)；不改变数值版本；现已接入键位/界面。模型审计更新仅改变报告的模型资料与完整输入哈希，不改变8张数值CSV结果；渐次实战防空效果仍未新增平衡试算。

可编辑数值放到[design-data](../../design-data/README.md)，不要在文档、表格和程序中维护三份互相冲突的公式。
