# 炮位、攻击能力与控制方式（target-v1.3.0）

自研目标规则现已接入游戏目标内核和操作面板，实际范围与验证限制见[运行说明](runtime-target.md)。此前“副炮和防空炮都是自动炮”的表述不准确：**炮位、攻击能力、控制策略是三个独立维度**。

最终收口：数值版本仍为target-v1.3.0/schema3；操作规则修订1补齐选炮组、AP/HE与对空引信、齐射/渐次、逐管共享状态和自动组停火。操作修订不改变数值输入，新增独立[操作状态回放](../../design-data/reports/weapon-controls.json)，不将它计作新增蒙特卡洛防空结果。随后模型审计更新重新生成完整输入哈希/模型资料，8张数值CSV结果逐字节不变。

## 1. 三个维度与编辑源

| 维度 | 定义 | 真值 |
|---|---|---|
| 配装位置 | main主武器、secondary第二武器、light_aa独立小口径防空组 | [ships.csv](../../design-data/source/ships.csv)与[automation.csv](../../design-data/source/automation.csv)记录物理数量；[controls.csv](../../design-data/source/controls.csv)显式引用位置 |
| 攻击能力 | surface对舰、air对空；同武器可以有两种模式 | [weapon_modes.csv](../../design-data/source/weapon_modes.csv)，17条模式覆盖16种武器，不含控制字段 |
| 控制策略 | manual玩家操作/指挥、automatic自动索敌开火 | [controls.csv](../../design-data/source/controls.csv)，32条配置覆盖全部12舰已占用位置；available_modes为本配装开放的能力子集 |

`secondary`也可装鱼雷，不能一律称为副炮。`manual`对航母主武器表示玩家指挥航空攻击，不表示存在一组手动防空主炮。`light_aa`是这里的小口径专用炮组，不能代表该舰全部历史防空装备。20/40级组分别保留独立装填与备弹，controls只声明共同控制政策，不再次增加炮管。

历史武器ID里的`_auto`仅为配置名，不决定炮位或控制。自动控制器读取明确的controls策略；校验确保自动炮组与该策略、开放能力和物理管数一致。将副炮改为手动时需同时撤除对应自动炮组，不能保留一份自动输出再增加一份手动输出。

模式表的普通行必须range/max_elevation/burst_radius=0、damage_multiplier=1，表示继承原武器模型；普通模式数值在weapons表编辑，非零覆盖会被拒绝，避免配置被静默忽略。本版自动surface条目明确对应secondary控制配置，aa条目对应light_aa；尚未增加自动主炮控制器。air模式的目标必须为飞机。弗莱彻对空限定HE定时引信，不增加第三种可选炮弹；它与20/40级使用HE的自动直击抽象不同。

## 3. 弗莱彻手动两用主炮：目标假设

| 项目 | 数值/规则 |
|---|---|
| 物理主炮 | 原4座单管；不增加炮管、不复制额外AA主炮 |
| 对舰参数 | 原初速165u/s、3.5秒装填、450HP、最大仰角28°、原散布与穿深，全部保持 |
| 对空范围 | 水平距≤1600u；目标高度与截击弹道另验可达性，最大仰角75° |
| 对空弹种/引信 | HE，定时球形爆炸；30u半径内每弹337.5HP（450×HE倍率1×0.75），无距离衰减；不是近炸追踪必中 |
| 弹药 | 140发/管；对舰/对空共用，不是每个模式各140发 |
| 装填/切换 | 共用next_fire；模式切换等待2.5秒，不重置装填、不补弹；切换等待与装填并行，取较晚就绪时刻 |
| 初始整备 | 7秒；t=0切到防空时仍最早7秒开火，不把切换等待强行另加成9.5秒 |
| 权衡 | 主炮对空期间不能同时对舰；独立20/40级自动组可继续射击 |

这些是可编辑自研起点，不是用户确认的历史装备数值，也不是已校准真人水平。切换到对空并不能突破物理射程/仰角。状态实现见[manual_aa.py](../../tools/balance/manual_aa.py)；对舰主炮旧试算仍隔离副炮与航空，新状态验证不冒充完整海空混战。

## 4. 截击、散布与引信试算

[manual_aa_scenarios.csv](../../design-data/experiments/manual_aa_scenarios.csv)为6个输入：两类航母各3档误差；各生成automatic_only、manual_only、combined三种对照，共18条结果，每条300次。种子43111，自动/手动使用分别派生的配对随机流；开启另一组不会改变随机数生成规则，但击落/目标变化仍会改变后续索敌与射击，不保证合用伤害等于两种单用伤害相加。

飞机高度120u、横向间隔80u、沿x方向同速平飞，中心线起点1600u，全部在x=350u投弹线结束；6机速度65u/s、进场19.2308秒，3机80u/s、进场15.625秒。投弹线不是每架飞机到舰心都恰好350u。80u间距大于爆炸直径60u，避免一发HE因为飞机重叠而免费打全波。

主炮求低弧移动截击根：

```text
(x+vx*t)² + y² + (z+0.5*g*t²)² = (炮口初速*t)²
```

扫描正时间区间并二分首次变号；仰角超限/无低弧解则不开炮。本版不采用高弧替代。每轮一个共同提前量误差和水平/垂直角误差，每管独立原武器均匀面积椭圆散布与引信误差；引信时刻按飞机真实位置判球形距离。散布作为爆点水平偏移代理，不是逐炮座精确3D误差锥。

| 档位 | 每轮水平/垂直角误差标准差 | 每轮提前量误差标准差 | 每弹引信均匀误差 |
|---|---:|---:|---:|
| ideal | 0° | 0秒 | 0秒 |
| practiced | 1° | 0.2秒 | ±0.1秒 |
| rough | 3° | 0.5秒 | ±0.3秒 |

ideal仍有原武器散布，不是必中；三个名称只指假设输入，不是“高手/普通/新手”的测量。角度/提前量使用零均值正态，引信使用均匀分布；实际仰角限制在0–75°。每轮4管共同预瞄一个目标，可能过量伤害，不在炮弹飞行中改目标。

自动小口径组保持原命中概率、射距、数量、锁定、转速与弹药；新对照仅改为展开编队，飞行距离计入高度。它仍是固定概率模型，并未模拟高射弹道。主炮有限转速、炮座遮挡、人工选目标与真实输入延迟未模拟；手动试算使用确定性选目标与给定误差，不能称为玩家胜率。

到达/爆炸事件按时间顺序处理；投弹前已死飞机不能投弹，已死目标上的伤害浪费；投弹后在途弹不能减少本次投弹伤害。manual_effective_hits只计已爆炸且命中存活飞机的事件，与旧自动AA发射时预判命中计数不可混用。

## 5. 结果与比较边界

完整精度见[manual-air.csv](../../design-data/reports/target-v1/manual-air.csv)与[生成报告](../../design-data/reports/target-v1/balance-report.md)。以同一新编队的自动单用为对照，观察手动瞄准误差如何影响击落，以及合用时是否增强护航；不把两个单用结果机械相加。

300次新编队试算的平均击落（自动小口径组参数未改）：

| 来袭波次 | 误差档 | 自动单用 | 手动主炮单用 | 合用 |
|---|---|---:|---:|---:|
| 约克镇6机 | ideal | 0.0233 | 1.0833 | 1.5000 |
| 约克镇6机 | practiced | 0.0233 | 0.9700 | 1.1967 |
| 约克镇6机 | rough | 0.0233 | 0.0900 | 0.4800 |
| 独立3机 | ideal | 0 | 0.9833 | 1.0000 |
| 独立3机 | practiced | 0 | 0.7900 | 0.9700 |
| 独立3机 | rough | 0 | 0.0300 | 0.2367 |

practiced合用时6机损失约19.94%、3机约32.33%；对应期望投弹伤害11888.25/3572.8HP，无防空为14850/5280HP。手动主炮能补足护航的主动防空职责，但小波次合用压力仍需试玩评估，不能宣称当前已经平衡。误差较大时效果显著下降，体现操作窗口与瞄准的代价。

v1.2.3的[automatic-air.csv](../../design-data/reports/target-v1/automatic-air.csv)保留1200u起点、同坐标飞机的简化基线，弗莱彻只统计20/40级小口径组。这解释了此前几乎零击落不等于该舰所有防空能力都无效。新编队起点/空间布局不同，不能用新表减旧表宣称某个百分比提升；BB重防空缺口也仍存在。

验收包括全部炮位覆盖、能力/控制引用、自动管数一致、手动副炮无需自动组、同一主炮切换共用弹药与装填、球爆高度/边界、间距防止全波重叠、低弧端点/仰角、误差档与三种组合、投弹后在途不阻止攻击。主炮、对射、房间、其他解析、原自动副炮与原自动AA结果应与v1.2.3完全一致；报告仍不是全舰队防空已平衡。

## 6. 最终操作规则：先选组，再选用途与弹种

### 6.1 操作分层与建议键位

以下是**自研交互方案，不是已接入的游戏键位，也不是原版按键复刻**。当前运行版的C镜头、左键瞄准、空格齐射等功能不改动。具体键位后续可重绑定，不能改变资源与控制规则。

| 操作 | 建议输入 | 规则 |
|---|---|---|
| 选择炮位/检查装备 | 1主武器、2第二武器、3小口径防空 | 空位禁用；自动组只进入检查面板，不因选择变成手动；航空/鱼雷显示各自指挥面板，不进入舰炮开火器 |
| 选择发射炮座 | B循环全部→第1座→第2座… | 只用于手动舰炮；炮座编号来自配装的mounts/barrels，不凭编号猜测艏/艉位置；艏/艉筛选需后续真实炮位挂点映射 |
| 对舰/对空用途 | Alt+Z或用途按钮 | 仅对开放surface/air的同一物理组生效；当前只有弗莱彻主炮开放手动对空 |
| 炮弹 | Z循环AP/HE | 对舰按武器能力开放AP/HE（HE-only组只开放HE）；对空固定HE并显示“定时防空引信”，不循环出第三种AA炮弹；对空尝试AP明确拒绝 |
| 齐射/渐次 | X或射击方式按钮 | 改变发射组织，不改变射速、散布、伤害或装填；不自动开火 |
| 预瞄/开火 | 左键指定瞄准点；空格开火 | 齐射按一次只打一轮，按住不重复；渐次按住时持续发出受节拍约束的开火请求，松开立即停止；模式/炮组/炮座/射击方式变化、失焦及退出战斗均解除按住状态，需重新按下 |
| 自动组开关 | P或该组启用按钮 | 只开关当前自动炮位；副炮与小AA分别开关；不切成手动，也不影响其他炮位；不提供“自动瞄准主炮” |

开火请求的目标种类必须与用途一致：surface对应舰船，air对应飞机。对空主炮仍由玩家预瞄/射击，不能仅切到air就获得自动索敌。改变用途时，界面应清除旧用途的瞄准指示，要求新的有效预瞄，避免拿海面点直接打飞机。

自动副炮继续按现有射界内DD优先、距离、ID索敌；自动小AA按距离、剩余HP、ID索敌。有效目标未失效前保持锁定，不因查看或切换手动主炮目标而重选；无有效可见敌目标不消耗弹药。没有新增玩家指定自动目标、跨舰集火或“手动抢占自动炮组”行为。

### 6.2 共享状态与切换

物理炮管是资源归属单位，炮位是控制政策单位。每个手动组保存：当前用途、AP/HE、记忆的对舰弹种、射击方式、每管备弹/就绪时刻、用途/弹种切换就绪时刻、发射节拍和下一管游标。**选中状态只改变操作者正在查看/操作哪一组，不复制武器，也不补弹、重装或重置节拍。**

- 初始整备仍为7秒。原齐射防空实验默认全部炮管同时开火，保持原结果。
- 用途变化：弗莱彻surface→air切为HE定时引信；air→surface恢复此前选定的AP或HE。HE的对舰接触用途与对空定时用途是同一备弹池的两种使用方式，不新增独立AA弹仓。
- 弹种或用途实际变化都读取该炮位的`mode_switch_s`；弗莱彻为2.5秒，其他炮位仍为现有0秒附加切换等待。0不是免装填，而是没有额外换装等待。**不新增另一份换弹延迟常数**。
- 切换与每管装填并行，发射时取所有相关等待的较晚时刻。切换不退还已发射弹、不改变在途弹的弹种/引信，不把装填中的时间归零。
- 同一弹种/用途的重复命令为幂等，不延长等待。等待中真正切回另一状态，则从最新有效切换时刻重新计算等待；不得靠反复切换缩短冷却。
- AP/HE和两种用途共享每管备弹；一管发一弹只扣该管1发。先前统一的140发/管不是AP140+HE140，更不是surface140+air140。
- 同组没有同时对舰与对空的火力；不同物理组可以并行。某管打空不影响其他管渐次发射，但全组齐射要求选中的每管都有弹且装填完毕；不会悄悄退化为少管齐射。
- 命令时间必须有限、非负且不倒退；错误选择/不支持的模式或弹种明确拒绝。错误目标种类不扣弹、不启动装填。

### 6.3 齐射/渐次：组织火力，不送额外DPS

齐射一次发射选中炮座内全部炮管（默认全组），每管从本次发射时间独立计算`reload_s`。渐次一次成功请求只发一管，按固定循环游标寻找选中范围内有弹且就绪的炮管；**节拍为该物理全组`reload_s / 全组炮管数`**，单座选择不重新计算或清空节拍。

每次成功开火后更新同组发射节拍；齐射/渐次、全部/单座之间切换仍共用它。渐次每管也必须等待完整reload_s，不能将reload_s/N误当作单管装填。输入中断时不排队、不补发“本来该打”的炮弹；恢复按住只按当前时刻继续请求，不突然补打一整轮。改变射击组织本身没有额外切换延迟，但不能绕过每管装填、用途切换和当前节拍。

弗莱彻4管×3.5秒示例（t=0切air，原7秒整备）：

| 时刻 | 渐次发射炮管（展示编号从1起） | 该管下一次就绪 |
|---:|---:|---:|
| 7.000秒 | 1 | 10.500秒 |
| 7.875秒 | 2 | 11.375秒 |
| 8.750秒 | 3 | 12.250秒 |
| 9.625秒 | 4 | 13.125秒 |
| 10.500秒 | 1 | 14.000秒 |

在[7,42)这35秒的持续有效开火窗口内：齐射为10轮×4管＝40弹；渐次为40次×1管＝40弹，每管各10弹。渐次只是分散爆发、便于逐次修正预瞄，不获得射速或命中率加成。单座射击减少瞬时输出，无法让该座突破单管装填。

本轮**没有将渐次模式加入原18条手动AA蒙特卡洛场景**。该状态回放不能证明渐次提高实际击落率；运动目标选点、每次瞄准误差与在途过量伤害都可能改变效果，需后续单独配对实验或试玩。

### 6.4 自动组暂停、恢复与界面反馈

自动组默认启用，关闭后不再索敌/新发射，但保留炮管、剩余弹药、炮口转向和装填截止时间；已经发射的在途弹由原事件队列继续结算，不因停火消失。关闭/重新开启清除旧目标锁定；重新开启后重新索敌并等待原`lock_s`，同时仍受未完成装填限制。反复开关不补弹、不免锁定、不重置冷却；主炮不会被自动AA接管。

面板必须分别显示：

1. 实际舰名、炮位、武器口径、炮座/炮管总数，以及手动/自动标识；自动状态另示“已启用/已停火”。
2. 当前选中全部或哪一座、surface/air、AP/HE与引信用途、齐射/渐次；未开放按钮灰显并注明原因。
3. 每管剩余备弹与装填进度、组切换倒计时、下一次发射节拍；逐管不同步时不能只显示一个会误导的“全组已装填”。
4. 当前用途射程/仰角/射界、目标类别、有效预瞄指示；不能显示“1600u内必可击中”，要提示低弧不可达。
5. 阻止发射的具体原因：未选择有效目标、目标种类不符、不可达/超界、切换中、所选炮管装填中、节拍等待、缺弹、自动组不可手动开火。

这里的按钮、失焦/按住处理、瞄准清除、炮座遮挡与转速反馈是**后续游戏集成契约**，不是已实现界面。离线[controls.py](../../tools/balance/controls.py)只执行炮组选择、资源、模式/弹种、目标种类、发射组织和自动启停；不负责可见性、距离、弹道、遮挡或真实按键。游戏集成必须先验证有效预瞄和物理可达，再授权扣弹。航空指挥、鱼雷发射另走各自控制器，本工具明确拒绝将它们当舰炮发射。

## 7. 回放、验证与交付边界

数值编辑源仍为前述CSV：数量看ships/automation，弹道/装填/备弹看weapons，能力看weapon_modes，控制政策及切换等待看controls。渐次节拍由既有装填和物理管数派生，不重复维护数值。状态回放输出来自代码与这些CSV，不手改JSON。

从项目根目录用工作区虚拟环境的Python运行：

```sh
python tools/balance/controls.py
python tools/balance/controls.py --verify
python -m unittest discover -s tests/balance -p 'test_*.py' -v
python tools/balance/run.py --check
python tools/balance/run.py --verify
```

[weapon-controls.json](../../design-data/reports/weapon-controls.json)包含4组确定性回放：共享装填、渐次不重置、弹种/目标类别约束、自动组检查/启停。JSON炮管/炮座编号从0起，界面示例从1起。操作修订1、原数值版本和CSV输入SHA256分别标注；42项单元测试通过，原11产物逐字节复现，单独回放也可逐字节复现。

最终状态：12舰特点、真实舰名、模型候选、主炮公式、近防副炮、小口径自动AA和弗莱彻主动两用防空已有独立编辑源/试算；控制政策不再靠“副炮/防空炮”名称推断。仍未完成BB重防空、专职防空CL扩充、真人输入误差校准、渐次实战击落对照、多舰防空叠加、完整炮位遮挡/转速、所有模型许可及游戏集成。小波次损失偏高仍需试玩，不宣称这是最终平衡定稿。

## 8. 《大海战2》参考与自研差异

参考2015年Steam版玩家指南，非完整官方手册：

- [NF2 Newbie Guide](https://steamcommunity.com/sharedfiles/filedetails/?id=407142908)：C在全部/前/后炮组间选择，Z切弹种，X切Salvo/Gradual，E更新集中瞄准；支持防空弹的两用炮可转为对空用途。文中备用弹种不是“副炮”。
- [Becoming an Admiral](https://steamcommunity.com/sharedfiles/filedetails/?id=406910668)：区分Automatic AA与玩家用舰炮防空弹预瞄飞机下红圈射击，也提到独立AAA位置，但不足以确认全部炮组的具体控制规则。
- [Anti-Air Gunning guide (For auto control users)](https://steamcommunity.com/sharedfiles/filedetails/?id=422521878)：讨论提前量及渐次开火；auto control是操作模式，不能据此断言玩家主炮自动打飞机。其部分示意图属于NF1，不用来证明NF2规则。

原作独立主/副/AA选择键、固定切换时长、共用装填/弹仓以及引信操作未可靠确认。本方案的2.5秒共享切换门、逐管装填、AP/HE两弹种加HE定时用途、30u球爆及渐次节拍均为自研规则，不归因于NF2。为保留当前C镜头方案，也不照搬C炮组选择；采用炮位与用途分层来避免概念混淆。
